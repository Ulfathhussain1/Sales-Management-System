# Sales-Management-System
The Sales Management System (Sales Intelligence Hub) is a web-based application developed using Python, Streamlit, MySQL, and SQL to manage sales operations, customer records, payment transactions, and branch-wise financial performance.

The system provides a centralized platform for recording and monitoring customer sales, tracking payments, calculating pending balances, and generating financial summaries to support business decision-making. It uses a MySQL relational database to store and manage data efficiently, with primary key and foreign key relationships to maintain data integrity.

The application includes a role-based login system with separate access levels for Super Admins and Admins. Super Admins can view information across all branches, while Admins can access information specific to their assigned branch.

The dashboard presents sales information, customer sales records, payment history, branch-wise sales summaries, and financial reports. SQL queries are used to retrieve, filter, join, aggregate, and analyze data. Automated database triggers help update payment-related information when new payment records are inserted.

The project demonstrates the practical integration of Python, SQL, database management, and Streamlit to build a user-friendly business application for sales tracking, financial monitoring, and reporting.

**Key Features**

•	Role-based login and access control
•	Branch and customer sales management
•	Sales and payment tracking
•	Pending balance monitoring
•	Multiple payment methods, including Cash, UPI, and Card
•	Automated payment-related record updates using SQL triggers
•	Branch-wise sales summaries and financial reports
•	Interactive dashboard for business insights
•	MySQL database with primary key and foreign key relationships
•	SQL-based data retrieval, filtering, joins, and aggregations
